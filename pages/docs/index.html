Docs & FAQ

How do I create an app?

Open Studio Builder, enter the target website URL, configure the application details, preview the result, and start the build workflow.

Where are saved apps stored?

The current Builder stores project history in the browser's LocalStorage on the device and browser where the project was created.

Does the generated APK represent a real signed production APK?

The current front-end build workflow is a browser demonstration and source-code generator. A production Android signing/build pipeline requires an actual Android build environment and signing credentials.

Can I customize the app?

Yes. The Builder exposes application identity, colors, splash screen, orientation, icon, permissions, and related settings.
