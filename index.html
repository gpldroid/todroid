Documentation & Frequently Asked Questions

How do I build and install the generated Android project?

The Studio exports a real Android Studio project as a ZIP. Open it in Android Studio, sync Gradle, then build a debug APK or configure signing for a release APK/AAB.

Can I publish this application to Google Play Store?

Yes. Export the Android Studio project, open it in Android Studio, sync Gradle, configure a release keystore, then generate an APK or Android App Bundle (AAB).
